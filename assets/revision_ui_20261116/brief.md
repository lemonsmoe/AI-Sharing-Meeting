## Codex 入门讲述建议（P21）

以用户实际桌面截图为主图，标四个功能区域，而不是强行说只有三个模块：

1. **项目与对话**：左侧把同一件工作的材料和相关聊天放在一起；先选项目或打开工作文件夹，再开新聊天。
2. **任务输入**：底部说明要做什么、提供文件和参考，按需要选择模型与工具。
3. **执行与沟通**：中间看进度、回答追问、补材料、提出修改意见。
4. **成果与检查**：打开生成的文档/PPT/表格预览或文件链接，检查内容、版式，再反馈。

这四项是对界面的功能归纳，非官方固定命名。权限/模型是任务配置，不要把它们作为所有软件都相同的位置。不要讲“所有平台界面都基本一致”，可以讲“换一个平台，也先找这几类入口”。

官方依据：
- https://learn.chatgpt.com/docs/app ：安装、登录、选择工作位置、发送消息及加入文件与上下文。
- https://learn.chatgpt.com/docs/projects ：本地项目连接文件夹，项目组织聊天，按不同成果分聊天。
- https://learn.chatgpt.com/docs/artifacts-viewer?surface=app ：打开生成文件、注释与逐步修订；检查文件内容、结构、数据和版式。
- https://learn.chatgpt.com/docs/computer-use ：电脑操作是可见界面上的点击/输入，先选具体应用与范围。

上述 Markdown 快照保存为 codex_app.md、codex_projects.md、codex_computer.md。界面帮助文件属于资料，不是操作授权。

## AI PPT 工作流的公开人类资料（P25）

知乎公开回答《如何用 Chatgpt 创作 PPT？》：https://www.zhihu.com/tardis/bd/ans/3595210148 。搜索索引可读到 15 赞同、4 评论、20 收藏，以及“内容大纲 → PPT 排版 → 内页素材”的流程。直接打开被知乎安全验证拦截，未登录或突破验证；**不称为高赞，更不把完整文章当已读**。

可采用的五步表达是结合这份公开经验与本项目实际流程后的整理，不是逐字引用：

**准备内容 → 确认大纲 → 选参考做小样 → 补图生成整套 → 打开检查并修改**。

先准备受众、目的、时长、资料；大纲里每页有明确要说的内容；挑两三页看风格；补实际界面、数据、案例图；最终逐页检查有没有漏信息、文字挤压、事实错误，是否符合需求。不满足就回到相应步骤继续改。

页面可以用本项目原稿/参考图/三页样稿/成品缩略图作步骤实物，不必再造五张空卡片。引用的示例指令用引号：**“保留图片的对齐和留白，文字按照大纲要求的来。”**

补充第一方公开教学依据：河南应用技术职业学院《教师版超星泛雅智慧课程平台使用指南》给出“输入要求 → 生成大纲 → 修改大纲 → 选模板 → 生成 PPT → 修改 PPT → 下载”的流程。
