# 五个可执行教程入口

这些是下一步试用步骤，除已链接的Codex示范外尚未执行。每条采用模拟资料，记录首次输出、改动和账号额度；不承诺耗时。现有授权账号可直接试，缺账号或权益则记录不可执行，不在本轮注册付费。

## T01 资料到一页报告（ChatGPT / Claude / 豆包）

1. 准备同一份公开或模拟资料，例如：项目A完成8项、待办2项；项目B完成6项、待办4项；没有延期原因。
2. [ChatGPT官方入口流程](https://learn.chatgpt.com/docs/web)：选择可用的研究/交付入口，粘贴资料；[Claude文件教程](https://support.claude.com/en/articles/12111783-create-and-edit-files-with-claude)：检查文件创建开关；[豆包官网](https://www.doubao.com/chat/)：从新对话粘贴同一资料，不依赖未核实的文件按钮名称。
3. 提示：只据材料生成一页项目简报，区分事实与待确认；保留全部数字；不要猜延期原因。可生成文件时交付可编辑文件，否则交付可复制正文。
4. 验收：8/2/6/4是否一致，缺失原因是否标待确认；另存首次输出。可读文字不等于已交付可编辑Word，按实际结果登记。

## T02 文件夹到纪要及清单（WorkBuddy / Codex）

复用现有[tutorials/office/file_demo](../../../tutorials/office/file_demo/execution_record.md)的input和prompt.txt；只复制输入到独立演示文件夹，不把参考输出放进去。

1. [WorkBuddy首任务](https://www.workbuddy.cn/docs/workbuddy/FirstTask)完成已有账号登录；或按[Codex/桌面快速开始](https://learn.chatgpt.com/docs/quickstart)打开文件夹。
2. 明确任务：读取input两份文件，输出到新output目录；保留原文件；生成meeting_brief.md及action_items.json，未知负责人和日期写待确认，不发消息。
3. 检查每项待办的来源，区分已决定、提议、已完成；打开两个实际文件，确认不是仅聊天承诺。
4. WorkBuddy官方[文件处理指南](https://www.workbuddy.cn/docs/workbuddy/From-Beginner-to-Expert-Guide/Practice-Cases/Practice-One)另提供批量改名流程。首次练习先生成预览清单；确认规则后才能改演示副本。

## T03 在已有办公套件内改文件（Copilot / WPS）

1. 复制含上述两项目数据的4页演示或简单文档；先确认[M365许可](https://learn.microsoft.com/en-us/copilot/plan/copilot-license-options)已分配，或WPS客户端可见AI权益。
2. WPS按[官方PPT步骤](https://www.wps.cn/article/jT0fHn8o.html)：演示→WPS AI→一键生成→粘贴大纲→确认→选模板。Copilot在对应Office应用内输入同一任务，不以免费网页聊天代替应用内功能。
3. 指令：保留项目数字，用一页表格对比完成与待办，不添加原因。生成后修改一个数值并保存、关闭、重开。
4. 验收文字、表格和图表数据分别可改；不会随工作簿更新的图表单列问题。本项目已有[原生PowerPoint限制记录](../../slides/native_powerpoint_check.md)，不能当Copilot成功证据。

## T04 会议到行动项（飞书 / Notion）

1. 使用自编2分钟模拟会议并取得参演者同意；包含一项明确承诺、一项待定日期、一项已完成工作。
2. 飞书按[智能纪要帮助](https://www.feishu.cn/hc/zh-CN/articles/244959839578-在视频会议中使用智能纪要)检查是否能启用AI总结/录制；当前步骤来自官方索引正文，客户端入口和权益待实核。若不可用不猜按钮。
3. Notion按[会议笔记指南](https://www.notion.com/help/ai-meeting-notes)使用AI Meeting Notes入口。远程会议优先检查桌面系统音频和麦克风采集，浏览器仅收麦克风不能视为完整采集。
4. 核对逐字稿→摘要→待办三层；未承诺的日期不能变截止日，已完成工作不能重复安排。先私下检查，不自动分享或创建真实任务。

## T05 大纲到可编辑演示（Gamma）

1. 使用T01相同事实，编成4段大纲：目标、原始数据、进度对比、待确认事项。
2. 已有账号中新建演示，粘贴内容，限定4张卡片并生成；逐项核对数字和缺失项。
3. 按[官方导出教程](https://help.gamma.app/en/articles/8022861-what-s-the-easiest-way-to-export-my-gamma)：Share/Export→All cards→PowerPoint。
4. 在实际使用的Office/WPS里逐页核对，修改文字与一个图表数据，保存重开；记录水印和图片化元素。成功导出PPTX不等于所有对象可编辑。

共用记录列：工具/账号套餐/客户端版本/输入哈希/首读与保存时间/首次输出路径/人工修订/事实错误/导出可编辑性/消耗额度。该记录方案是教学候选，不是新增产品横评结论。
