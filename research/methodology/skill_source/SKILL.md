# AI 工具与工作流调研

先读取 [研究门槛](references/research_gate.md) 与 [证据及审查模板](references/evidence_review.md)。门槛是严格研究模式默认基线；项目存在更新基线时记录版本差异并遵循明确授权，不自行降标。数量不是可信度评分。

明确任务、使用者、平台、输入、交付格式与可检验质量条件。第一轮发现候选并及时保存草稿；第二轮主动找失败及限制，再针对缺口补证。未达门槛保留为草稿，不以凑链接代替读取。

先登记原始来源再写结论。同一稿件转载、同作者跨平台和同一案例转述合并证据组；独立作者数另算，不能把多条 URL 当多个独立实例。搜索摘要仅作线索。不可访问的视频记录尝试，不声称已观看；完整字幕只支持文字内容，不能证明画面或音频质量。

研究主推项时比较至少三条独立路线，核验官方能力限制与费用，再找独立实例和负面证据。按门槛做两次独立实测；分别保存完整输入、提示词、版本、输出、人工修改、耗时与错误，对照事先质量检查及基线。未实际运行必须写待验证。

独立审查模式：先仅看主题和拟验证问题，保存带日期的反证检索与结论，再读被审报告；没有报告只能交反证材料与审查准备，不能宣称验收。审查者身份与作者不同；同一 Agent 自检不能冒称独立审查。不自动创建聊天或子代理。

交付来源台账、主张证据矩阵、实测记录、门槛逐项缺口及推荐状态。候选、实测通过、审查通过和项目最终验收分别记录。定价和产品能力标访问日期；不将官方宣传视为本地效果。两轮后证据仍不足，交清晰缺口及下一步，不无限浏览。
