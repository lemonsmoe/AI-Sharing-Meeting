# Microsoft Copilot：会议纪要与行动表（待实测）

先核对实际入口，Chat与Cowork是同一产品路线的不同条件，不能拆开凑三路线。官方Cowork文档列出Copilot许可、环境启用及按用量计费前提；本任务未授权新增计费，遇到要求开通则停止在该入口。

1. 使用已有账号进入官方Copilot；记录Chat/Cowork、账号类型、版本与可见额度。没有Cowork时仅测已有Chat并注明差异。
2. 新会话上传O1两份模拟txt，贴shared_o1_prompt.txt；不引用组织邮箱、Teams或其他工作资料。
3. 发送并保留首次完整回答。Cowork官方说明结果在右侧面板，可下载文件；本账号能否做到仍需实测。
4. 下载纪要和表格，核对会后变更、未知与采购状态，测试日期排序。只返回文字时记文件能力缺项。
5. 修订另存后用新会话复测。需要许可证、计费或管理员启用时记录具体提示，不自行开通。

依据：https://learn.microsoft.com/en-us/copilot/cowork/get-started （35—90行；更新2026-11-03）；https://support.microsoft.com/en-us/microsoft-365-copilot/get-started-with-microsoft-365-copilot-chat （121—181行）。访问2026-11-09；界面正在发布中，可能不同。
