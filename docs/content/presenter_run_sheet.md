## 故障时直接读（单次排查不超过20秒）

- **网络或在线工具不可用**：“今天使用已经保存的模拟材料和结果，不依赖现场重新生成。我们先看输入、交付和核对方法。”继续本地PPT，不反复登录。
- **报价文件打不开**：“材料要求100件、9天内到货。A总价9240元且7天，B交期未知，C虽9000元但10天。这说明价格和交期都要按同一口径核查。”指第10/12页继续。
- **Excel打不开**：“第24页是实际工作簿节选。报告有负责人和期限，收集报价的两个字段仍空白；采购未批，网络不是已确认根因。文件能编辑，不代表未决信息已经解决。”指第24页图片，不声称现场兼容通过。
- **视频无声、卡顿或打不开**：“样片用三步解释会议整理：先看原文，再区分决定、待办和未知，最后核对来源。它是代码动画加系统旁白，本次设备播放尚未通过；完整文件可会后查看。”停止播放，转第28页；不将静音画面当作音画验收。
- **PPT无法放映**：打开已备好的逐页预览HTML，按同页码继续。若浏览器和文件也不可用：“现场文件暂时无法打开，先用一个任务说明方法：给材料、说清交付、保留未知、逐项核查。”随后进入交流，不宣称演示成功。
