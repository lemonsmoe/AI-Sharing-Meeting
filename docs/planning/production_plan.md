## 选型原则（用户已确认）

## 制作步骤（提案）
1. 研究包：核实概念关系与历史，比较会议/PPT/办公/视频工作流，保存官方来源、独立实践、失败限制及价格日期。
2. 内容脚本：逐页一句主张、演示证据、画面设想和讲述时间；补齐具体制作方案。
3. 小样：先制作提示词前后对照、PPT流程、办公案例三类代表页，加一段60—90秒讲解视频样片；验证视觉与讲述节奏后扩展。
4. 完整交付：PPT、演讲备注、演示录屏、教程、提示词模板、来源与成本说明，检查Office/WPS显示和视频播放，按55分钟总预算排练。
5. 复用：从已经完成的案例中剪出一条独立短视频作为首个作品候选；公开前选择可公开素材并另行确定发布范围，不默认发布。

Agent负责研究、脚本、方案、可执行范围内的文件制作与检查；需要账号登录、用户声音、真实操作或专有材料时，给用户明确步骤和最小需求。用户提供素材、审阅表达风格和重要取舍。无需用户先写完整讲稿。

## 素材按需提供
最新纠偏：模板已提供；不再要求用户提供写作示范或先想办公任务。Agent先研究并给出可选择的场景菜单，自然写作只占小议题。

视频开始前确认：本人配音、AI配音或混合；是否出镜；先做样片再确定剪辑工具。
需要尽早补充的排期信息：分享具体日期、可排练日期。网络账号条件、数据许可和实际付费预算在入围实测前确认。
