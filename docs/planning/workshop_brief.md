# 培训目标与框架评审

记录日期：2026-11-06。来源：本轮用户说明、公司分享.md 和本轮 Agent 建议。

## 用户明确要求
- 面向同事，主题为目前 AI 主流用法与企业使用，帮助提高职场效率。
- 需要 PPT、工具推荐、教程、成果和可信的效率证据。
- 推荐要有真实社区使用和较好反馈，并适合中国企业环境。
- 保存多轮讨论，支持多智能体研究、重复验证和后续主对话接续。
- 用户计划另开主对话进行 PPT 探讨与设计。
- 参考资料包含一个 PPT 成果和插件截图；同学推荐的智谱模型加插件是待核实线索。

## 原框架
AI 原理（语音、文本、图像、视频）→ 各模态工具前三、最小说明书、产出效果 → 注意事项 → 个人认知。工具场景包括会议纪要、PPT、生图、宣传视频、办公与代码；设想全套 PPT 用 AI 制作，并参考 B 站教程做 Claude AI 讲解视频。

## 本轮建议（尚未被用户确认）
1. 以工作任务为主线：会议录音到行动项、材料到汇报 PPT、资料到文稿、表格到分析、需求到宣传素材。编程作为按受众选择的拓展。
2. 原理只解释理解能力边界所需的概念，避免占据主要培训时间。
3. 各场景提供一个主推、一个备选及适用条件；完整候选比较放附录，避免强行排出前三。
4. 用同一份公开或脱敏输入展示人工基线、AI 初稿、人工修订和最终成果。耗时包含核查与返工，不编造提升百分比。
5. 注意事项嵌入各教程：输入材料边界、事实核查、导出与编辑问题、失败时的替代步骤。
6. PPT 与讲解视频制作过程本身可作为案例，但视频是否制作及投入应在时长明确后决定。

## 暂定叙事顺序
工作痛点与示例 → 必要原理及边界 → 3 至 4 个可复现工作流 → 选型方法 → 公司试用方式 → 个人经验与问答。
