# 领导审阅版交付约定

目标：2026-11-09晚形成首份可审阅内容版，满足用户11月10日前审阅需求；11月16日分享。

## 必须可审阅的内容
- 约30页逐页标题、唯一主旨、正文要点、讲述稿及预计时间；总时长控制在55分钟左右含问答机动。
- 主线覆盖AI用法与能力关系、提示词和协作、会议/PPT/办公场景、视频应用；例子服务主线。
- 每个关键事实有来源；主流、前沿、已实测、作者个案、待验证明确区分。
- 工具选型有主推/候选/平替及适用条件，不强行三强排名；有账号或成本障碍仍提交可评估方案。
- 明确哪些是录屏、概念动画、现场演示；备有静态结果，可在不联网时讲述。
- 优先提供可打开PPT内容审阅稿及讲稿；若视觉或视频仍在迭代，标注待改项，不能以空白占位当已交付。

## 从研究包到成稿
主对话只将证据合格的结论纳入正文；缺证据的有用探索可进入附录候选。收到研究初稿后先审查核心主张与例子，再整合逐页脚本。PPT子聊天提供路线实验，视频子聊天提供样片，以实际结果决定最终生产方式。

## 生产验收
PPT须检查渲染、中文字体、溢出、图表、备注、来源链接和Office/WPS兼容边界；未实开其中之一不能声称已通过该软件验收。视频须检查可解码播放、字幕与画面、配音同步（有配音时）、音量、片头片尾与可复现工程。最后实际试讲计时，计入所有视频。
