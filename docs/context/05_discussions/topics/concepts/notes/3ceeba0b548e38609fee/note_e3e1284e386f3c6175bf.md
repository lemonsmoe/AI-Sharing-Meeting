# 两轮V2执行及矛盾核验教学候选

12份真实回答已评分，保留一处首尾矛盾和非因果边界

- 来源对话：`01a1b055-e174-7dc2-80bf-176bbcae9c0a`
- 来源位置：2026-11-06本聊天实际读取两轮原始输出、manifest及冻结scoring_v2后评分；教学用法为本轮Agent建议

## 0 · 观察或调研结果

来源登记已22条，3份发布方完整字幕实际读完；R1独立审查已执行并整改。两聊天V2共12份首次回答已评分，16项输入输出哈希一致。trial_02 E1-A首段选甲、末段选乙，选择结论判错误；其余共同事实项正确。详见experiments/trial_scoring_report.md。

## 1 · 约束

每个聊天全部A/B提示一并可见、回答共享上下文，实际工具调用不同且旧题型已暴露；两聊天重复执行不能证明提示词因果提升。人工基线和新增证据及评分的独立复审仍缺，不宣称研究门槛全部通过。

## 2 · 候选方案

教学可展示第二轮E1-A金额正确但建议首尾冲突，说明交付前需核对建议和表格一致；同时展示第一轮A本就正确，避免制造短提示必错印象。本轮Agent建议，待主对话采纳。
