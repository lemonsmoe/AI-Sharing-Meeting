# 概念补证与来源资格

历史与评分已合稿，Skill前向使用已交；S19不计详细实践，新增S23有输入环境失败路径的替补候选，未自动放行总门槛

此文件整理讨论，不代表方案获准实施。引用可追溯到独立记录。

## 候选方案

- 按能力层组合解释概念，避免线性代际；12页候选已保存。（[note_7fd0540c9511275e9b09#0](notes/3ceeba0b548e38609fee/note_7fd0540c9511275e9b09.md)）
- 提示词前三页围绕同一报价案例展示从模糊请求到材料、工具和交付文件，避免连续规范清单；版本见case_slide_revision.md。（[note_a65076a82285604d42d4#0](notes/3ceeba0b548e38609fee/note_a65076a82285604d42d4.md)）
- 科普章节以任务可拆分程度解释多Agent适用性，结合Anthropic与Cognition对照；不把多Agent当默认升级。详见research/concepts/counterevidence_review.md。（[note_b12ac83b211e2eb31199#0](notes/3ceeba0b548e38609fee/note_b12ac83b211e2eb31199.md)）
- 教学可展示第二轮E1-A金额正确但建议首尾冲突，说明交付前需核对建议和表格一致；同时展示第一轮A本就正确，避免制造短提示必错印象。本轮Agent建议，待主对话采纳。（[note_e3e1284e386f3c6175bf#2](notes/3ceeba0b548e38609fee/note_e3e1284e386f3c6175bf.md)）
- 主屏采用双行8节点时间线、下方共存条，讲述按用法变化展开；作为能力分类页的历史补充或替换由主对话定，暂不改总页数。（[note_8ad0bc3094f59b5e5955#2](notes/3ceeba0b548e38609fee/note_8ad0bc3094f59b5e5955.md)）
- 如后续要验证响度流程，先定平台、声道、容差和版本，保留最终编码文件测量日志并完整试听核对发音/失真及同步。本轮Agent后续候选，未实施。（[note_0f7cbc39dc47e0b992d8#2](notes/3ceeba0b548e38609fee/note_0f7cbc39dc47e0b992d8.md)）
- 提请以S23替补薄弱S19作为第六组详细实践候选；不是原6组上加成7组，也不自动接受其他组或整体研究门槛。（[note_4fc446e67e13d686c999#1](notes/3ceeba0b548e38609fee/note_4fc446e67e13d686c999.md)）

## 约束

- 原阶段约束（独立复核进度见新增记录）：每个聊天全部A/B提示一并可见、回答共享上下文，实际工具调用不同且旧题型已暴露；两聊天重复执行不能证明提示词因果提升。人工基线和新增证据及评分的独立复审仍缺，不宣称研究门槛全部通过。（[note_e3e1284e386f3c6175bf#1](notes/3ceeba0b548e38609fee/note_e3e1284e386f3c6175bf.md)）
- 图中日期为论文/产品/工程实践公开时间，不等于发明或大众普及；2026托管方案仅为代表实践。MCP、Skills、Agent可组合共存，直接API仍可用。（[note_8ad0bc3094f59b5e5955#1](notes/3ceeba0b548e38609fee/note_8ad0bc3094f59b5e5955.md)）
- 独立复核非盲评，未审计底层完整聊天日志；本次是阅卷后评分解释澄清，不追溯声称预登记没有歧义；仍不推断提示词因果效果或人工节时。（[note_daa951b6843e070eb865#2](notes/3ceeba0b548e38609fee/note_daa951b6843e070eb865.md)）
- 官方支持单次处理，不能说单次必失败；参数目标不等于成片实测，也不能替代中文试听和同步验收。本轮无媒体实测，只拒绝缺依据的直接推荐。执行者参与项目且知道方向，不是盲测，不能将表现因果归功于Skill或宣布全部门槛通过。（[note_0f7cbc39dc47e0b992d8#1](notes/3ceeba0b548e38609fee/note_0f7cbc39dc47e0b992d8.md)）
- S23缺精确模型版本、完整会话和输出diff，未本地复现；只支持有归因的历史实践，不推出当前产品缺陷、Skills无效或通用效率收益。（[note_4fc446e67e13d686c999#2](notes/3ceeba0b548e38609fee/note_4fc446e67e13d686c999.md)）
