# 视频样片与实践资格校正

V07排除直接实践：4署名加1匿名条件组，六实践及完整音画仍未通过

此文件整理讨论，不代表方案获准实施。引用可追溯到独立记录。

## 候选方案

- 代码动画先建立可复现骨架，必要时补真实录屏或生成镜头；仍为候选路线。（[note_8344c34ef59289d78093#0](notes/f70d4c23e33e8b96bd2c/note_8344c34ef59289d78093.md)）
- 旁白版验收核对真实时长、镜头边界、字幕和语义；由主对话制作旁白，本聊天避免重复写入。（[note_7627529f8ba89c4ea95b#2](notes/f70d4c23e33e8b96bd2c/note_7627529f8ba89c4ea95b.md)）
- 交付仅留一层底部字幕：替换摘要条或避免同名SRT自动叠加，修改后核对实际播放器。（[note_3847282c1fbfa29677a9#1](notes/f70d4c23e33e8b96bd2c/note_3847282c1fbfa29677a9.md)）

## 观察或调研结果

- 首轮仅字幕样片与部分文章阅读；后续已读Ploto长片正文，原片仍未观看。V2为72秒24fps，1728帧解码和72个逐秒帧检查完成；未完成动态播放。正文14份，官方完整可见转录1、镜像全文2身份待核对，研究门槛仍缺。（[note_8344c34ef59289d78093#1](notes/f70d4c23e33e8b96bd2c/note_8344c34ef59289d78093.md)；[note_7627529f8ba89c4ea95b#0](notes/f70d4c23e33e8b96bd2c/note_7627529f8ba89c4ea95b.md)）
- 中文实践中发现fps计算不一致及缺逐镜失败证据，不能作为已核验效率或模型胜负。（[note_7627529f8ba89c4ea95b#1](notes/f70d4c23e33e8b96bd2c/note_7627529f8ba89c4ea95b.md)）
- 旁白版独立解码通过，但默认libass三处截图显示SRT遮挡摘要，第三条标点断行不当；未试听或动态审片。（[note_3847282c1fbfa29677a9#0](notes/f70d4c23e33e8b96bd2c/note_3847282c1fbfa29677a9.md)）
- 独立caption_candidate_01已生成72秒单层字幕候选，六段最终编码截图无字幕遮挡或行首句号，音轨哈希保留且完整解码通过；未完整试听动态播放，原版未改。（[note_108790d0f0e294bf4ae8#0](notes/f70d4c23e33e8b96bd2c/note_108790d0f0e294bf4ae8.md)）
- 主对话已读审查与复现、查看四个时刻截图，准备采用caption_candidate_01为V3随包首选；不代表完整音画验收。（[note_5e4d199eaa05ea8d54cc#0](notes/f70d4c23e33e8b96bd2c/note_5e4d199eaa05ea8d54cc.md)）
- 补读原作者流程与完整配套转录、商业合成案例、AAEE教学试验后，来源组17、独立实践保守4、完整视频文字2；n=15课后自述不证明客观成绩提升。（[note_5e4d199eaa05ea8d54cc#1](notes/f70d4c23e33e8b96bd2c/note_5e4d199eaa05ea8d54cc.md)）
- Kevin作者官网嵌入ID与全文镜像标题日期及案例对应，来源组18、完整文字内容3（含两个镜像）；未逐字核原声，原片观看0，独立实践及双次独立创作和音画验收仍缺。（[note_cc5eec0bfe42f64f78ca#0](notes/f70d4c23e33e8b96bd2c/note_cc5eec0bfe42f64f78ca.md)）
- 新增社区语音同步返工及个人源码实践，来源组20、候选非厂商实践6；匿名与转述限制待审，制作顺序无统一效率结论，V3完整音画与双次独立执行仍缺。（[note_1be1a2662b4ee1c7c7d5#0](notes/f70d4c23e33e8b96bd2c/note_1be1a2662b4ee1c7c7d5.md)）
