# 新30页讲稿的办公教学候选和缺素材讲法

连续通知例子贯穿提示词；办公三种候选留待选择；用户补素材前可用通用讲法推进排版。

- 来源对话：`01a1dfb9-8ef0-7681-8152-9732ce5ade1f`
- 来源位置：本对话 2026-11-15 新结构讲稿委托及本轮 Agent 内容建议，见 docs/content/swiss_script_20261115/case_options.md。

## 0 · 候选方案

第8–12页用活动通知从周三改周五的虚构例子串起任务、背景、样例、修改与回源。标明教学示意，避免提前定成公司的办公案例。

## 1 · 候选方案

第14–15、20–21页备选三种教学示例：用现有模拟会议核一条改期及采购状态；用公开说明做带出处对照表；用虚构 Excel 数据复核口径。未经选择，正稿沿用通用操作。

## 2 · 候选方案

公司表情包素材若赶不上，可保留短讲，按用途、手机缩小检查和系列一致性讲实际做法；有图再替换素材位。第24页若新版原生表格尚未核，可用已测第一轮版本并清楚标注。
