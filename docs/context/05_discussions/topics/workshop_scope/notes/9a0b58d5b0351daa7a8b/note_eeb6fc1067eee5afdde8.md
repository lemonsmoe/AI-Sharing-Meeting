# 制作方案与素材清单

2026-11-06。大纲 V1 和三项教学重点已由用户确认作为推进基线，允许后续修订。以下具体制作步骤与衍生作品为 Agent 提案。

## 双重目标
本次交付约30页、少于1小时的全员分享；长期积累用户做UP主、剪辑、制作高质量PPT和AI讲解视频的能力。制作过程保存研究来源、提示词、输入输出、人工修改、录屏和耗时，便于复盘与后续创作。

## 已知环境（用户提供，未技术核验）
Office/WPS并用；飞书承载正式群与流程，微信日常交流，用友用于物料审批等。CEO自建知识库，服务器运行用户所称ds模型、openui等工具（确切名称版本待核实）。有带显卡的服务器、ESXi虚拟机环境及GitLab。尚未核查GPU型号、资源余量、推理或训练适配；当前不部署、不接入内部系统。

## 选型原则（用户已确认）
先展示前沿、大公司和业界广泛使用的方式，再比较费用及平替；允许付费工具入围。前沿与广泛使用分别寻找证据，不因品牌或宣传直接推荐。兼顾中国企业使用条件。研究候选不等于购买或部署决定。

## 制作步骤（提案）
1. 研究包：核实概念关系与历史，比较会议/PPT/办公/视频工作流，保存官方来源、独立实践、失败限制及价格日期。
2. 内容脚本：逐页一句主张、演示证据、画面设想和讲述时间；补齐具体制作方案。
3. 小样：先制作提示词前后对照、PPT流程、办公案例三类代表页，加一段60—90秒讲解视频样片；验证视觉与讲述节奏后扩展。
4. 完整交付：PPT、演讲备注、演示录屏、教程、提示词模板、来源与成本说明，检查Office/WPS显示和视频播放，按55分钟总预算排练。
5. 复用：从已经完成的案例中剪出一条独立短视频作为首个作品候选；公开前选择可公开素材并另行确定发布范围，不默认发布。

Agent负责研究、脚本、方案、可执行范围内的文件制作与检查；需要账号登录、用户声音、真实操作或专有材料时，给用户明确步骤和最小需求。用户提供素材、审阅表达风格和重要取舍。无需用户先写完整讲稿。

## 素材按需提供
第一批可选：一份可使用的公司PPT模板或喜欢的视觉参考；一段本人写的300—800字文章或通知，用于自然写作对照；一项典型办公任务及脱敏输入。暂缺时使用公开或模拟材料并标注，不阻塞研究。
第二批在案例确定后收集：短会议录音或转写、对应表格/文档、所需工具账号套餐情况、演示录屏。
视频开始前确认：本人配音、AI配音或混合；是否出镜；先做样片再确定剪辑工具。
需要尽早补充的排期信息：分享具体日期、可排练日期。网络账号条件、数据许可和实际付费预算在入围实测前确认。

## 概念研究范围
用户所列提示词—MCP—Skill—Agent—Harness是粗略理解，明确允许纠正补充。研究时评估上下文工程、检索增强/知识库、工具调用、工作流编排、评估反馈是否应纳入；这是研究问题清单，不是已验证历史顺序。

## 验收边界
本轮只完成范围与制作方案整理，没有开始工具实测或生成PPT/视频。公司基础设施来自用户描述，不代表模型或部署已经兼容。具体步骤、样片与衍生作品尚为提案。
