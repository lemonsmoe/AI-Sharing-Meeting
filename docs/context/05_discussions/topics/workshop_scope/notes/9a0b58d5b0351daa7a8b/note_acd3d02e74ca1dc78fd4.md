## 教学提案
- 主线：怎样把工作交给 AI，并把结果改到可用。提示词贯穿具体案例。
- 用同一任务展示含糊提问、补充背景材料、明确交付标准、多轮修改的差别；少背咒语式模板。
- 自然写作演示：提供本人样文、读者、事实细节和语气要求，删空泛套话，保留真实信息；不编造个人经历，不以检测器得分验收。
- PPT 制作过程采用成果开场、过程回看；记录真实输入、人工改动和耗时，不把未实施步骤讲成成功案例。
- 录屏建议 2—3 段，总长控制 3—4 分钟并计入各章节；用途为稳定展示过程，不能当作额外免费时间。
