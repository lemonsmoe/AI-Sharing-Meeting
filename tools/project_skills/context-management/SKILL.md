# 项目协作上下文

一个入口负责初始化和日常接续。SQLite 管任务认领，Markdown 管知识，AGENTS.md 管执行规则，Hook 提供短背景和提醒。原始聊天仍由 Codex 保存，不自动复制进项目。

## 选择模式

- 新项目或尚无工作流：使用下面的初始化入口。
- 已有工作流需要检查、迁移或升级：先 `doctor`，再预览 `init`；不要重新初始化数据库或替换项目事实。
- 日常接续：直接查询任务状态、读当前索引和相关领域；无需重复安装或每轮调用初始化。
- 项目构思或头脑风暴：有新方案、约束、问题、异议或取舍理由就保存为讨论记录，不等待最终决定；同轮完成相关议题整理。包括本轮回答中 Agent 新提出的建议，不能只整理旧笔记却漏掉新观点。见 [讨论记忆](references/discussion_memory.md)。无新增信息的普通解释可不留档。

## 初始化与升级

脚本位置相对于本技能目录。使用可用的 Python 3.11+，把示例中的路径、项目名和对话 ID 替换成真实值。不要把示例 ID 当成已注册身份。

```powershell
python <技能目录>/scripts/context_setup.py init --root <项目绝对路径> --project-name <项目名> --manager-thread-id <用户指定的真实主对话ID>
```

默认只预览。确认输出符合本次授权后，同命令加 `--apply` 才写入。脚本自动创建项目目录层次、默认文档、SQLite、项目规则和三个 Hook；不需要用户手工准备这些文件。新项目必须明确主对话，侧边讨论或自动创建的工作对话不自动升为主对话。项目目标可从当前讨论写入生成的索引，未确认内容标为候选。

```powershell
python <技能目录>/scripts/context_setup.py doctor --root <项目绝对路径>
python <技能目录>/scripts/context_setup.py init --root <已有项目绝对路径>
```

已有 AGENTS.md 仅追加受管区块；已有项目事实、任务、决策和手册保持原文。已有 Hook 合并保留。升级只替换安装清单中未被手工修改的程序与受管区块，先备份；发现冲突停止，不使用强制覆盖。已有项目应用升级由真实主对话执行，并先按旧工作流认领写入范围。预览和 doctor 可由普通对话运行。

Hook 配置或脚本变化后由用户在 Codex 中审阅信任，不能代为批准。新对话是否真实加载，以回执与模型实际收到的背景为准，不能把手工运行脚本当作真实触发。[Hook 官方说明](https://learn.chatgpt.com/docs/hooks)。

## 日常执行

1. 开始任务、恢复或压缩后，运行 `python scripts/context/task_store.py status` 和 `python scripts/context/discussion_store.py sync`，读当前索引、相关领域和有变化的议题。工具代发的消息不保证触发 UserPromptSubmit，显式查状态。实际读完后按返回版本 ack；注入或列出路径不算读完。
2. 持久修改前 `create` 列全写入范围和验收标准，再 `claim`。身份使用真实 `CODEX_THREAD_ID`；冲突时协调原责任人释放，不冒名、不超时夺权，不绕过脚本覆盖。
3. 实际子任务完成时追加独立事件、刷新相关领域，再 `finish --result ... --evidence ...` 到 review。只有主对话 `review --accept`。回复结束不等于任务完成；没有结果不能自动释放。
4. 主对话在阶段交接或跨域决定落定时更新总索引、决策索引和手册。普通对话只维护认领领域和自己的事件。模板见 [记录模板](references/update_templates.md)，操作与限制见 [使用说明](references/usage.md)。

核验只针对本任务依赖：稳定结论按来源变化核验，设备与风险操作临执行前复核。建议、用户确认、已实施、已验证分开写；事实核验时间不能凭空刷新。

认领是协作机制，不是文件权限锁。Hook 不直接总结聊天；discussion_hook 的 Stop 可在本对话留下待整理记录时请求当前模型补做一轮，已补做则不循环，失败保留队列。未提取成记录的聊天仍可能遗漏。需要独立回滚的并行 Git 实现使用独立分支/worktree，并指向同一个主上下文根，不复制数据库。

## 完成汇报

精简说明已完成内容、证据、当前任务状态和未验证项。初始化后说明 Hook 待信任；离线自检不代表真实生命周期、压缩恢复或真机已验收。
