# 两页上屏候选

## 主屏：先认任务，再选工具入口

副标题：代表性候选，不是使用率或效果排名

| 你要交付什么 | 可以从哪里开始 |
|---|---|
| 一份有依据的报告 / 中文初稿 | ChatGPT · Claude · 豆包 |
| 一批整理好的本地文件 | WorkBuddy · Codex |
| 现有文档、表格、演示里的修改 | Microsoft 365 Copilot · WPS AI |
| 会议纪要与后续行动项 | 飞书智能纪要 · Notion |
| 从大纲到演示文稿 | Gamma（也可走现有办公套件） |

页底：先用同一份模拟材料试做，再看许可、数据权限、费用和复核成本。

讲述建议：这些入口都在往多步骤交付扩展，能力会重叠。我们按同事的任务来认路，既看通用研究，也看文件Agent、办公套件和会议知识库；不因大厂品牌就认定最好或最普及。中文办公候选包括豆包、WorkBuddy、WPS和飞书，但是否适合公司仍需同题试用。

主屏来源随备注携带：comparison.md中的逐项官方链接；豆包/飞书为官方索引正文，在线完整页面待复核。

## 附录：开始前，确认账号与计费单位

| 工具 | 最少准备 | 费用怎么看 |
|---|---|---|
| ChatGPT | 账号、功能开放、资料 | 订阅额度；Work/credits |
| Claude | 账号、文件创建开关 | 订阅及用量；文件也耗额度 |
| 豆包 | 官方账号、可用功能 | 会员额度；价格看客户端 |
| WorkBuddy | 客户端、授权文件夹 | 订阅积分、加量包 |
| Codex | 已登录环境、目录和工具 | 订阅/credits或独立API账单 |
| M365 Copilot | 组织许可、管理员分配 | 按用户；部分高级AI按用量 |
| WPS AI | WPS账号与AI权益 | 会员/企业套餐与功能额度 |
| 飞书 | 纪要权限及可用额度 | AI额度与转写分钟分开 |
| Notion | 适用套餐、音频权限 | 按成员与账期 |
| Gamma | 账号、大纲、导出检查 | 月/年订阅与AI credits |

页底：2026-11-06核验。当前只实做了Codex模拟文件任务；其余为官方能力核对。费用和权限以实际账号为准，未开展采购或付费试用。
